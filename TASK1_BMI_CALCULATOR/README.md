A command-line BMI(Body Mass Index)Calculator has been built in Python as part of the Oasis Infobyte Python Programming Internship.

# How to run
python srivalli_Task1.py

# Requirements
1.Python 3.x..version, My python version is 3.14.3
2.No external libraries needed

# Features
1.Accepts weight in kilograms and height in meters
2.Calculates BMI using the formula: (weight / height^2)
3.Classifies result into 4 categories:
  ->Underweight (BMI < 18.5)
  ->Normal weight ( 18.5 <= BMI < 25 )
  ->Overweight ( 25 <= BMI < 30 )
  ->Obesity (BMI ≥ 30)
4.Handles invalid input, using try/except
5.Validates the values which are Positive and Realistic
