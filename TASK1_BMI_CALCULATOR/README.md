# BMI Calculator - Task 1

A command-line BMI(Body Mass Index)Calculator built in Python as part of the Oasis Infobyte Python Programming Internship.

# Author

Jajala Srivalli - Oasis Infobyte Python Programming Internship

# How to run

python srivalli_Task1.py

# Requirements

1.Python 3.x..
(Developed using 3.14.3)

2.No external libraries required

# Features

1.Accepts weight in kilograms and height in meters

2.Calculates BMI using the formula: 
   BMI = (weight / height^2)

3.Classifies result into 4 categories:
  ->Underweight ( BMI < 18.5)

  ->Normal weight ( BMI < 25 )

  ->Overweight ( BMI < 30 )

  ->Obesity (BMI ≥ 30)

4.Handles invalid input using try/except

5.Validates positive and realistic input values
